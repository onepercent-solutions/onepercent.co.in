# OnePercent — onepercent.co.in

Static website for [onepercent.co.in](https://onepercent.co.in) — SAP BTP Consulting, Open Source & Learning Ecosystem.

## Tech Stack

- Plain HTML5, Vanilla CSS, Vanilla JavaScript (no build step required)
- Hosted as a static site

## Structure

```
onepercent.co.in/
├── index.html      # Main page
├── styles.css      # Design system & all styles
├── app.js          # Interactive logic (nav, BTP visualizer, contact modal)
├── image.png       # OnePercent logo
└── design.md       # Design system documentation
```

## Running Locally

```bash
python -m http.server 3000
```

Then open [http://localhost:3000](http://localhost:3000).
